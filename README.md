# GemmaCode

Локальный ИИ-агент для программирования и работы с вашим компьютером на моделях **Gemma 4** (E2B по умолчанию, E4B и 12B по выбору). Читает и правит файлы, запускает команды, пишет код, открывает страницы во встроенном браузере и принимает фото и звук прямо в модель. Всё работает на вашей машине: ни код, ни файлы, ни разговоры не уходят в облако, а после загрузки модели сеть не нужна.

Статус: **бета (0.5)**. Интерфейс в духе Codex и OpenCode: слева проекты и сессии, в центре чат с лентой действий и diff, справа вкладки (файлы, редактор, изменения, терминал, браузер, предпросмотр, статистика). Любую сессию можно откатить.

## Скачать

Готовые установщики лежат на странице [Releases](https://github.com/YoruKitsune/GemmaCode/releases) вместе с `SHA256SUMS.txt`.

| Система | Файл | Заметки |
|---|---|---|
| macOS (Apple Silicon) | `GemmaCode-…-mac-arm64.dmg` | проверялась на MacBook Air M1 8 ГБ |
| Linux x64 | `GemmaCode-…-linux-x86_64.AppImage`, `…-amd64.deb` | AppImage: `chmod +x`, затем запуск |
| Windows x64 | `GemmaCode-…-win-x64.exe` | бета, проверена меньше всего; песочница слабее, чем на macOS и Linux |

**Сборки не подписаны** (сертификатов Apple и Windows нет), поэтому система предупредит:

- *macOS:* «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» либо `xattr -dr com.apple.quarantine /Applications/GemmaCode.app`.
- *Windows:* SmartScreen → «Подробнее» → «Выполнить в любом случае».

`llama-server` (движок llama.cpp) уже внутри установщика. Модель в установщик не входит: при первом запуске окно предлагает скачать её с Hugging Face (одним файлом с докачкой после обрыва и проверкой SHA-256).

## Модели

| Модель | Скачать | Память машины | Для чего |
|---|---|---|---|
| **E2B** (по умолчанию) | около 4 ГБ (с проектором для фото и звука) | от 8 ГБ | быстрая, помещается на M1 8 ГБ |
| E4B | около 6 ГБ | от 16 ГБ | точнее в вызовах инструментов и коде, медленнее |
| 12B | около 7,3 ГБ | от 24 ГБ | самая сильная |

Окно показывает по каждой модели, хватит ли памяти вашей машины, до загрузки. Лицензия моделей Gemma 4: Apache 2.0.

### Скорость, честно

Цель проекта была 60 ток/с на M1 8 ГБ, и **она не достигнута**. Измерено на M1 8 ГБ с E2B Q4_K_M: чистая генерация около 20 ток/с; на правках файлов спекулятивный декодинг по n-граммам даёт 25–40 ток/с (в среднем в 1,1–1,8 раза быстрее); кэш префикса сводит ожидание первого токена с 6 до 0,5 с. Подробности и методика: [docs/M4.md](docs/M4.md).

## Что умеет

- **Инструменты:** чтение, поиск, правка и создание файлов, команды в терминале, запуск программ хоста, браузер, скиллы, MCP-серверы. Права: «только чтение», «спрашивать» (по умолчанию), «авто-правки», «полный доступ». Команды идут в песочнице ОС (Seatbelt на macOS, bubblewrap и Landlock на Linux), данные из сети и внешних файлов помечаются недоверенными.
- **Вложения:** фото и аудио подаются в модель напрямую (перетаскиванием, вставкой, `@файл`). Видео не поддерживается.
- **Скиллы:** папки с `SKILL.md` в `~/.gemmacode/skills` и `.gemmacode/skills` проекта.
- **Из коробки:** встроенный браузер (агент управляет страницей через CDP, вы можете перехватить управление), предпросмотр (Markdown, HTML, PDF, CSV, JSON, изображения, аудио), файловый менеджер, статистика проекта (локально, экспорт в CSV и JSON).
- **Терминал:** `gemmacode` в консоли с теми же ядром и сессиями.

Приватность: [PRIVACY.md](PRIVACY.md). Безопасность и как сообщить об уязвимости: [SECURITY.md](SECURITY.md).

## Разработка

```bash
npm ci
npm run typecheck
npm test
cd apps/desktop && npm run dev
```

Нужен Node.js 22 или новее. Сборка установщика: `npm run dist:mac|linux|win` из `apps/desktop` (на своей системе: нативные модули берутся для неё; релизы собирает GitHub Actions). Как участвовать: [CONTRIBUTING.md](CONTRIBUTING.md).

| Каталог | Что внутри |
|---|---|
| `packages/core` | ядро: движок инференса, цикл агента, инструменты, права, песочница, скиллы, MCP, браузер |
| `packages/host` | сервис агента для окна: сессии, откат, файлы, терминалы, вложения, загрузка моделей |
| `packages/protocol` | типы запросов и событий окна и сервиса |
| `packages/cli` | `gemmacode` в терминале |
| `apps/desktop` | окно: Electron, React, TypeScript, упаковка |
| `eval`, `bench` | 50 задач оценки агента и стенд замеров |
| `docs` | документы этапов M0–M5 с замерами и решениями |
