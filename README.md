# GemmaCode

Локальный кроссплатформенный ИИ-агент для программирования и работы с хостом на Gemma 4 (E2B по умолчанию, E4B и 12B по выбору). Всё работает на машине пользователя, после загрузки модели сеть не нужна.

Статус: M0 завершён (замеры), M1 (ядро агента и CLI) завершён: архитектура в `docs/M1.md`, измеренные результаты в `docs/M1-eval.md` (гейт 20 из 30 пройден, 27–28 из 30). M2 (окно на Electron) описан в `docs/M2.md`, проверка с настоящей моделью в `docs/M2-mac.md`. M3 (встроенный браузер, предпросмотр, статистика; видео отменено) описан в `docs/M3.md` (там же проверка на Mac). План проекта и решения хранятся в проекте GemmaCode в Claude.

## Устройство

| Каталог | Что внутри |
|---|---|
| `packages/core` | ядро на Node: интерфейс `InferenceBackend`, запуск `llama-server`, цикл агента, инструменты, права, песочница, скиллы, MCP, сжатие контекста, режимы loop и само-ревью |
| `packages/cli` | `gemmacode`: агент в терминале |
| `eval` | 50 задач на правку и генерацию кода для измерения агента |
| `packages/protocol` | типы запросов и событий окна и сервиса, сборка ленты чата |
| `packages/host` | сервис агента: сессии, подтверждения, откат, файлы, терминалы, вложения |
| `apps/desktop` | окно GemmaCode на Electron, React и TypeScript: чат с diff, файлы, терминал, фото и звук, откат |
| `bench` | стенд замеров M0: выбор квантования, скорость, надёжность вызовов инструментов, мультимодальность. См. `bench/README.md` |

## Разработка

```bash
npm install
npm run typecheck
npm test
npm run build
npm run bench -- info      # стенд замеров
cd apps/desktop && npm run dev
```

Нужен Node.js 22 или новее. Если бинарник Electron не скачался (npm не выполняет install-скрипты), выполните `node node_modules/electron/install.js`. Движок инференса `llama-server` ставится отдельно (`brew install llama.cpp`).

## Известные упрощения M0

- Определения аргументов `llama-server` продублированы в `bench/lib/server.mjs` и `packages/core/src/inference/args.ts`, потому что стенд запускается без сборки. После выбора квантования стенд перейдёт на пакет `core`.
- Лицензия пока не выбрана (проект открытый, решение запланировано на M5).
