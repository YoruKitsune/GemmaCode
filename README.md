# GemmaCode

Локальный кроссплатформенный ИИ-агент для программирования и работы с хостом на Gemma 4 (E2B по умолчанию, E4B и 12B по выбору). Всё работает на машине пользователя, после загрузки модели сеть не нужна.

Статус: этап M0 (замеры и каркас). План проекта и решения хранятся в проекте GemmaCode в Claude.

## Устройство

| Каталог | Что внутри |
|---|---|
| `packages/core` | ядро на Node: интерфейс `InferenceBackend`, запуск `llama-server` и потоковый клиент, дальше цикл агента, инструменты, права |
| `apps/desktop` | оболочка на Electron, React и TypeScript; пока каркас компоновки (сессии, чат, правая панель) |
| `bench` | стенд замеров M0: выбор квантования, скорость, надёжность вызовов инструментов, мультимодальность. См. `bench/README.md` |

## Разработка

```bash
npm install
npm run typecheck
npm test
npm run build
npm run bench -- info      # стенд замеров
cd apps/desktop && npm run dev
```

Нужен Node.js 22 или новее. Движок инференса `llama-server` ставится отдельно (`brew install llama.cpp`).

## Известные упрощения M0

- Определения аргументов `llama-server` продублированы в `bench/lib/server.mjs` и `packages/core/src/inference/args.ts`, потому что стенд запускается без сборки. После выбора квантования стенд перейдёт на пакет `core`.
- Лицензия пока не выбрана (проект открытый, решение запланировано на M5).
