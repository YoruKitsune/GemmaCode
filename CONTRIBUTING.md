# Как участвовать в GemmaCode

Спасибо за интерес. Проект открытый (лицензия MIT), делается силами одного человека, поэтому небольшие точные запросы на слияние принимаются быстрее больших.

## Быстрый старт

```bash
git clone https://github.com/YoruKitsune/GemmaCode.git
cd GemmaCode
npm ci
npm run typecheck
npm test
cd apps/desktop && npm run dev      # окно с горячей перезагрузкой
```

Нужен Node.js 22 или новее. Если бинарник Electron не скачался, выполните `node node_modules/electron/install.js`. Для работы с настоящей моделью поставьте `llama-server` (`brew install llama.cpp`) либо скачайте модель кнопкой в окне; для тестов модель не нужна: они идут на поддельном сервере.

## Устройство репозитория

| Каталог | Что внутри |
|---|---|
| `packages/core` | ядро агента: цикл, инструменты, права, песочница, скиллы, MCP, браузер, движок инференса |
| `packages/host` | сервис агента для окна: сессии, подтверждения, откат, файлы, терминалы, загрузка моделей |
| `packages/protocol` | типы запросов и событий между окном и сервисом |
| `packages/cli` | `gemmacode` в терминале |
| `apps/desktop` | окно на Electron и React, упаковка |
| `eval`, `bench` | 50 задач для оценки агента и стенд замеров скорости |
| `docs` | документы этапов M0–M5, замеры и решения |

## Правила

- **Тесты.** Каждое изменение поведения сопровождается тестом. `npm test` в корне запускает все пакеты и набор `eval`; для окна есть `npm run test:e2e` и `test:smoke` в `apps/desktop`.
- **Типы.** `npm run typecheck` должен проходить без ошибок.
- **Без новых зависимостей без нужды.** Приложение должно оставаться лёгким: на M1 с 8 ГБ памяти каждый мегабайт на счету.
- **Безопасность прежде удобства.** Новый инструмент агента обязан проходить через слой прав (`packages/core/src/permissions`), данные из сети и внешних файлов считаются недоверенными.
- **Честные числа.** Если пишете про скорость или качество, прикладывайте замер и условия (машина, модель, квантование). Цель 60 ток/с на M1 8 ГБ не достигнута, и документы говорят об этом прямо.
- **Язык.** Интерфейс, документы и сообщения коммитов на русском; идентификаторы и комментарии к коду по месту, как в соседних файлах.

## Запрос на слияние

1. Форк, ветка от `main`, одна тема на запрос.
2. В описании: что меняется, зачем, как проверено (команды и результат).
3. CI (typecheck и тесты) должен быть зелёным.

## Сообщения об ошибках

Укажите версию (из имени файла установщика или `package.json`), систему и чип, модель и квантование, шаги воспроизведения. Не прикладывайте секреты и приватный код: логи и сессии лежат в `.gemmacode` проекта, просмотрите их перед отправкой.
